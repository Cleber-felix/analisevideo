What it is

Audiovisual language analysis, not transcription

The transcript already exists (inemaVOX/Whisper). What was missing was someone to look at the video and explain how it was made.

🎥 Camera, block by block

Each clip has a timecode: shot, angle, movement (dolly, gimbal, whip-pan, drone, orbital), speed, and what it does in the scene.

🎨 Lighting, color, and editing

Hex palette, lighting setup, look, and apparent lens; cuts per minute, pacing, transitions, cuts on the beat, and use of slow motion.

🗂️ Searchable database

Every analysis becomes JSON + a report and is added to a local index. Then you can search drone, search synthwave, stats.

How it works

From link to report in one call

Everything runs locally except the visual analysis, which is handled by Gemini.

link or file→ yt-dlp (≤480p)→ ffprobe: duration and format→ Gemini: a filmmaker's perspective→ analise.json + analise.md→ index.jsonl (database)

Why 480p

Color, lighting, and movement are easy to read at this resolution, and uploads are fast. Above 18 MB, the file is re-encoded to 360p/12fps for analysis only.

What it doesn’t do

Doesn’t run Whisper, return captions, or clone music. For speech, use inemaVOX; for cloning a track, use the musica skill.

Command only

In the bot, runs only on /analisevideo. A standalone link in Telegram still goes to the transcript, by design.

User guide · step by step

Analyze, read, and query

Real commands. S=~/projetos/apps/analisevideo/analisevideo.sh

1

Analyze a link

Downloads, reads the visuals, and archives. The report path appears on the last line.

bash $S analisa "https://www.youtube.com/shorts/XXXX"  # downloads, analyzes, indexes
2

Analyze a local file

Works for material yt-dlp can’t fetch (logged-in site) or for a clip that’s already been cut.

bash $S analisa ~/videos/reel.mp4 reel-marca --keep-src  # saves fonte.mp4
3

Focus the analysis on a question

--prompt adds a specific request, answered in the field pedido_extra.

bash $S analisa "<url>" --prompt "como eles seguram a atenção nos 3 primeiros segundos"
4

Read the report again

Markdown ready to paste into a brief, script, or work order.

bash $S ver reel-marca      # report
bash $S json reel-marca     # structured, for scripts
5

Query the database

This is where it becomes a library: search by movement, look, soundtrack genre, or tag.

bash $S list 10               # last 10 analyses
bash $S search "drone"       # everything with drones
bash $S stats                # most frequent movements and tags
6

On Telegram, through OpenPCBot

The skill is enabled as a bot command — it doesn't trigger on its own from a link.

/analisevideo <url|caminho>   # summary + analise.md attached
/analisevideo search drone
/analisevideo stats
